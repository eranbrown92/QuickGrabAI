# QuickGrabAI

QuickGrabAI is a powerful Chrome extension that lets you instantly capture and analyze any part of a webpage using OpenAI's advanced AI technology. Get quick, accurate insights from screenshots with just a few clicks.

## Features

- 🖱️ Quick screenshot capture with selection tool
- 🤖 AI-powered image analysis
- 📚 Analysis history with gallery view
- 🔄 Multiple analysis modes
- 🔒 Secure API key management

## Setup

1. Install QuickGrabAI from the Chrome Web Store
2. Get an OpenAI API key from [OpenAI's platform](https://platform.openai.com/api-keys)
3. Click the QuickGrabAI icon in your Chrome toolbar
4. Go to Settings tab
5. Enter your OpenAI API key

## How to Use

### Capturing Screenshots

1. Click the QuickGrabAI icon in your Chrome toolbar
2. Click the "Capture Screenshot" button
3. Draw a selection box around the area you want to analyze
4. Release to capture and analyze

### Tabs Overview

#### Capture Tab

- Main screenshot capture interface
- Click "Capture Screenshot" to start
- Use Escape key to cancel capture

#### Gallery Tab

- View all your previous analyses
- Click any analysis to view full details
- Analyses are sorted by date
- Click "Delete" to remove unwanted analyses

#### Settings Tab

- Set your OpenAI API key
- Choose analysis mode:
  - **Image Analysis**: General description of images
  - **Test Taker**: Specialized for answering test questions

### Analysis Modes

1. **Image Analysis Mode**

   - Provides concise descriptions of images
   - Best for general use
   - Identifies key elements in the image

2. **Test Taker Mode**
   - Specialized for test questions
   - Provides direct answers when applicable
   - Indicates when content isn't a test question

### Gallery Features

- Chronological view of all analyses
- Preview of analysis results
- Full-screen view available
- Delete individual analyses
- Persistent storage across sessions

## API Key Requirements

This extension requires an OpenAI API key to function. To get your API key:

1. Visit [OpenAI's platform](https://platform.openai.com/api-keys)
2. Create an account or sign in
3. Navigate to the API section
4. Generate a new API key
5. Copy the key and paste it in the extension's Settings tab

**Note**: Keep your API key secure and never share it. The extension stores your key securely in Chrome's storage.

## Privacy & Security

- All analysis is performed through OpenAI's secure API
- API keys are stored securely in Chrome's storage
- Screenshots are processed locally
- Analysis history is stored only on your device
- No data is shared with third parties

## Tips for Best Results

1. Make clear selections around the content you want to analyze
2. Use the appropriate analysis mode for your content
3. Ensure your API key is valid
4. Check the gallery for previous analyses before capturing duplicates
5. Use the delete function to manage your analysis history

## Troubleshooting

- If capture isn't working, ensure you're not on a Chrome system page
- If analysis fails, verify your API key in Settings
- Clear your analysis history if you're running low on storage
- Refresh the page if the selection tool becomes unresponsive
- Make sure you have an active internet connection
