QuickGrabAI Privacy Policy

Last updated: August 20, 2025

1. Information We Collect

QuickGrabAI is designed with privacy in mind. We collect minimal information necessary for the extension to function:

  • OpenAI API Keys: Stored securely in Chrome's sync storage, encrypted by Chrome
  • Analysis History: Screenshots and AI analysis results stored locally on your device
  • User Preferences: Selected AI model and analysis mode settings

2. How We Use Your Information

Your information is used solely to provide the extension's functionality:

  • API keys are used to communicate with OpenAI's services for image analysis
  • Analysis history is stored locally for your convenience and review
  • Preferences are saved to maintain your chosen settings

3. Data Storage and Security

  • Local Storage: Analysis history is stored only on your device using browser localStorage
  • Chrome Sync: API keys and preferences are stored in Chrome's secure sync storage
  • No Server Storage: We do not store any of your data on our servers
  • Third-Party Processing: Screenshots are sent to OpenAI for analysis using your provided API key

4. Third-Party Services

QuickGrabAI integrates with OpenAI's API service:

  • Screenshots are sent to OpenAI for AI analysis
  • OpenAI's privacy policy applies to data processed by their service
  • You control the API key and can revoke access at any time

5. Data Sharing

We do not sell, trade, or share your personal information with third parties except:

  • With OpenAI for image analysis processing (using your API key)
  • When required by law or to protect our rights

6. Your Rights and Choices

  • API Key Control: You can remove your API key at any time through the extension settings
  • Data Deletion: You can delete individual analyses or clear all history through the extension
  • Uninstall: Uninstalling the extension removes all locally stored data

7. Data Retention

  • Analysis history is retained until you manually delete it or uninstall the extension
  • API keys are stored until you remove them or uninstall the extension
  • We do not automatically delete any user data

8. Children's Privacy

QuickGrabAI is not intended for children under 13. We do not knowingly collect personal information from children under 13.

9. Changes to This Policy

We may update this privacy policy from time to time. We will notify users of significant changes through the Chrome Web Store or extension updates.
