QuickGrabAI Privacy Policy

Last updated: November 11, 2026 · Version 1.2.0

What the extension handles

QuickGrabAI captures the visible tab only when you start a capture. You select a region, which the extension crops on your device. Only that selected region and your analysis instruction are sent to OpenAI. The full visible screenshot is temporarily held in memory while you select. The extension does not independently collect your browsing history or send the page URL to OpenAI.

OpenAI requests

The extension uses your API key to fetch your available models from OpenAI and analyze selected screenshots. Requests go directly to api.openai.com using HTTPS. Your API account is billed by OpenAI. Requests set store: false to avoid storing the response for later API retrieval. This does not guarantee zero retention; OpenAI’s applicable API data policies govern its processing and retention.

Storage on your device

Your API key, preferences, and cached model list are stored in the extension’s local Chrome storage. This version does not sync them to your other devices. API keys are not sent to webpage scripts. Local extension storage is not an encrypted password vault.

During an upgrade, a previously synced API key is copied into local extension storage, then removed from the extension’s Chrome sync storage. Existing preferences and analysis history are migrated. A local rollback copy of old history is kept until you clear extension data or uninstall.

Pending cropped screenshots are kept in Chrome session storage so analysis can survive a page reload; they are removed after completion, when Chrome ends the session, or during cleanup after 24 hours when the extension next starts or captures. Unfinished selection tokens expire after five minutes.

Analysis history and your choices

When history saving is enabled, selected screenshots, thumbnails, results, model IDs, timestamps, and token usage are saved locally in IndexedDB. You can delete individual saved analyses in the gallery. Turning saving off stops new history entries; it does not delete existing history. Identical saved results can be reused locally to avoid sending another request. Remove your key in Settings, revoke it with OpenAI, or uninstall the extension to remove its locally stored data. Removing a local key does not revoke the key at OpenAI.

Sharing and remote code

QuickGrabAI has no developer analytics or developer-operated data server. It shares the selected screenshot and request data with OpenAI only to provide the requested service. It does not sell data, use it for advertising, or download executable code. Model responses are displayed as plain text.

Children and changes

QuickGrabAI is not intended for children under 13. Material changes will be reflected in this policy and the extension’s update information.
